# Sentiment-Bank-Jago-and-Revamp-Validation
End-to-end text analytics pipeline in Python using lexicon-based sentiment scoring, Linear SVM cross-check (TF-IDF/BoW), and keyword/regex issue detection. Issues are prioritized with priority_score = total_mentions × neg_rate. Top pain points: Login &amp; Access and Data &amp; Privacy, with high negative rates and low ratings.
